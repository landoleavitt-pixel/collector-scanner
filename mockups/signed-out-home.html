NOTES

What changes and what to watch

Headline per Landon: "The Grail Hunter, just try it." The name leads; "Just try it." sits right on top of the search box so the invitation and the action are one thing. The headline no longer explains the product, so the card strip directly below does that job: "One search. Rarest first." My pick: Option A, because "The Grail Hunter." reads as a name you remember, and the strip proves the claim. Option B is the verb version if a name feels too grand.
Accuracy fix for the live site (done). eBay can search several print runs at once, but only with a boolean search like (/10, /25, /49), which most collectors won't type. Per Landon, we say we make it easy. The live table row now reads: eBay "Searching several print runs at once means typing a boolean search, like (/10, /25, /49)." Us: "Easily pick every print run you want and see them together." Both options here fit that claim.
Real data rule. If the cached search ever comes back with fewer than six cards, the strip hides rather than showing placeholders. Lots and repacks are already filtered out of search.
