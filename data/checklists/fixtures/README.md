# Fake checklist fixtures

Everything in this folder is FAKE test data for scripts/test-checklists.mjs.
The player names are made up ("FAKE PLAYER ONE" and so on), and the numbers and teams don't match any real card.
The importer never writes these files out to lib/checklists/.

Real checklist files go in data/checklists/ (one level up), named with the set key.
